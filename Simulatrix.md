# Expansion of speculative ontology

In this new speculative ontology our current methodology aligns with the inverse memes → memes translation segment specifically for digital media. We can expand this by embedding digital representations of cortical columns and what I call the simulatrix.

The next step after the basic tagger implementation is to be able to internalise egregore tensors as patterns then we can pass in prompts which create anti-patterns and the internalised patterns of the files sort of bend to the anti-patterns to synthesise information such as asking for information about data.

Our tagger program uses the structure:  
Anchoring thoughtform → {thoughtform → strength}

We could convert this into a graph and model this as a matrix.  
The problem is that each of these matrices represent discrete states \- we can’t infer equations to relate these matrices for example usually if given the data 5,6,7 you could infer the next number is going to be 8 because the patterns seems to be that the sequence is increasing by 1 but because in this context 5,6 and 7 are discrete variables we cannot do this acting on the axiom of counting (that 5 induces 6 etc) however strengths give us a foundation that allow us to relate these symbols. 

In the brain we have a sense of direction using cells called place cells. They do a lot of special things however the way they work is when you exist in an area of physical or mental space called a place field the place cell activates and when you are not in that field it doesn’t activate. An example of a physical place field might be your hour house is divided into place fields \- your living room, your bedroom etc. Each of these areas of physical space corresponds to a set of different attributes and this is a place field.

In a way we can consider our egregore tensors as discrete bounded place fields \- the problem is that there is no inherent sense of travel between these fields however by calculating strengths between egregores we effectively create a sense of relative space.

The task is now to remember these place fields to create the cognitive maps as mentioned.
